# 🩺 MediGuide — دليلك الطبي الذكي

تطبيق موبايل ذكي يساعد المستخدم على إدخال أعراضه، 
فيقترح التخصص الطبي المناسب، ويعرض الأطباء القريبين 
مع إمكانية الحجز ومعرفة السعر.

---

## 🎯 المشكلة

- صعوبة معرفة أي طبيب يزور المريض عند الشعور بأعراض
- عدم شفافية أسعار الكشفيات
- صعوبة إيجاد طبيب قريب جغرافياً
- عملية الحجز تحتاج اتصال أو زيارة

## 💡 الحل

تطبيق واحد يجمع كل هاد:
- ✅ تحليل الأعراض → اقتراح التخصص
- ✅ إيجاد طبيب قريب
- ✅ حجز موعد إلكتروني
- ✅ معرفة السعر مسبقاً

## 🛠️ التقنيات المستخدمة

- **Frontend:** Flutter (Dart)
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL
- **AI:** Rule-Based System + Machine Learning
- **Maps:** Google Maps API
